# Luna Sofia Tique — Mi sueño en el mundo de la belleza

Sitio web personal académico construido con HTML, CSS y JavaScript. La portada incluye la fotografía de Luna Sofia Tique y presenta sus gustos, intereses y metas, especialmente su sueño de estudiar cosmetología y cosmiatría.

## Abrir en Visual Studio Code
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en el navegador o usa la extensión Live Server.

## Archivos
- `index.html`: estructura y contenido del sitio.
- `css/styles.css`: estilos adaptables a celular y computador.
- `js/script.js`: interacciones de navegación y formulario.
- `img/luna-sofia-tique.jpeg`: fotografía de portada proporcionada para el proyecto.
- `INFORME_PROYECTO.pdf`: informe académico.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube el contenido de esta carpeta, incluyendo `index.html`, `css`, `js` e `img`.
3. En el repositorio entra a **Settings → Pages**.
4. En Build and deployment selecciona `Deploy from a branch`, rama `main` y carpeta `/ (root)`; guarda.
5. Cuando GitHub lo publique, copia la dirección mostrada en esa sección y agrégala al informe.

Nota: el formulario es demostrativo y no almacena datos en un servidor. El enlace de GitHub Pages se debe completar después de publicar el repositorio.
